## v6.05 — V7 Phase 3: multi-dataset registry (session 13)
Phase 3 makes the tool multi-source, per PRD Phase 3. **Inline SheetJS (xlsx 0.20.3)** enables workbooks: the file input accepts CSV/XLSX with `multiple`, every sheet with a header row + data becomes a candidate dataset (raw:false keeps textual representations so leading zeros survive), and queued sheets confirm one at a time through the existing mapping panel.
